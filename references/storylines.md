# 叙事骨架

按场景选一个，再按时长裁剪页数。括号里是 15 分钟版本的大致页数（不含封面、章节页、致谢）。

## 学术报告 / 组会（论文工作）

1. 问题：临床或领域痛点，为什么重要（1 到 2）
2. 现状与缺口：已有方法做到哪、卡在哪（1 到 2）
3. 核心想法：一句话讲清本工作的关键洞见，配一张总览图（1）
4. 方法：按模块展开，每个模块一页，都回扣核心想法（3 到 4）
5. 实验：设置一页，主结果一页，消融或分析一到两页（3 到 4）
6. 结论与局限：回答第 1 部分的问题，坦白边界（1）

组会额外加一页「本周进展 / 下周计划 / 需要讨论的问题」。

## 开题 / 中期 / 结题答辩

1. 研究背景与意义（2）
2. 国内外研究现状与不足（2）
3. 研究目标与内容：总体框架图 + 各课题一句话（1 到 2）
4. 各课题：问题 → 方法 → 结果（中期、结题）或方案（开题）（每课题 2 到 3）
5. 进度与成果：时间轴、论文、专利（1 到 2）
6. 后续计划与风险（1）

中期、结题要如实写边界：评审会追问的弱点，提前在页面或 `（备）` 讲稿里准备好。

## 基金会评 / 项目答辩

1. 申请人与团队：每人一句定位 + 关键成果数字（1 到 3）
2. 立项依据：需求、现状、缺口（2 到 3）
3. 研究目标与内容（1 到 2）
4. 技术路线与研究方案（3 到 5）
5. 关键问题与创新点：难点、方案、验收判据三行对齐（1 到 2）
6. 研究基础与可行性：前期成果、平台、条件（2 到 3）
7. 预期成果与考核指标、转化（1 到 2）

每条主张都要能指回申报书原文；评委手里有申报书，PPT 与申报书口径不一致会被当场追问。

## 项目 / 工作汇报（面向领导或合作方）

1. 结论先行：一页讲清进展、成效、需要的支持（1）
2. 背景与目标（1）
3. 做了什么：按里程碑（2 到 3）
4. 效果：数据与案例（1 到 2）
5. 问题与下一步（1）

## 科普 / 课程讲解

1. 从一个具体场景或问题切入（1）
2. 核心概念，一页一个，配类比和图（3 到 5）
3. 把概念串起来解决开头的问题（1 到 2）
4. 小结与延伸（1）
